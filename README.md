# Linux 서버 운영 및 관리 실습

## 1. 프로젝트 소개
Linux 서버 구축 및 운영·관리 역량을 기르기 위한 개인 실습 프로젝트입니다.

## 2. 실습 환경
- 가상화 프로그램: VMware Workstation Player
- 운영체제: CentOS 8 DVD ISO

## 3. 프로젝트 목표

- VMware 가상 환경에서 Linux 서버 및 클라이언트 구축
- Linux 기본 명령어, 사용자·권한 관리 및 파일 관리 실습
- IP 설정, 서브넷 마스크, 게이트 웨이 등 네트워크 환경 설정 및 실습
- X 윈도우 환경 및 응용 프로그램 활용 실습
- 하드 디스크 관리, RAID, LVM을 활용한 스토리지 구성 및 관리 실습
- 웹·DB·메일·파일 공유 서버 설치 및 운영 실습
- 원격지 시스템 관리(Telnet, OpenSSH, XRDP)서버 구축 및 운영 실습
- 네임서버 설치와 마스터 네임서버 운영 실습
- 메일서버 설치와 메일서버 구현과 운영 실습 
- 데이터베이스(MariaDB, Oracle)서버 구축과 운영 실습
- 웹 서버(APM)설치와 운영, 클라우드 서비스 구축 실습
- 네트워크 파일 공유 서비스(FTP, NFS, Samba)서버 설치와 운영 실습
- PXE 설치 서버, DHCP 서버, Proxy 서버 설치와 운영 실습 
- 리눅스 방화벽 구축 및 네트워크 보안 설정 실습

## 4. 가상머신 환경 구성
서버 2대와 클라이언트 2대로 구성된 가상 환경 

## 5. 문제 상황
CentOS8에서 IP 설정과 네트워크 연결 문제
yum 저장소와 RPM 패키지 의존성 문제

## 6. 실습 내용
RAID 구성과 문제발생시 각 RAID별 차이와 복구 방식 이
