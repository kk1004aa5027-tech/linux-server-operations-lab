# Linux 서버 운영 및 관리 실습

## 1. 프로젝트 소개
Linux 서버 구축 및 운영·관리 역량을 기르기 위한 개인 실습 프로젝트입니다.

## 2. 실습 환경
- 가상화 프로그램: VMware Workstation Player
- 운영체제: CentOS 7 DVD ISO

## 3. 프로젝트 목표

- VMware 가상 환경에서 Linux 서버 및 클라이언트 구축
- Linux 기본 명령어, 사용자·권한 관리 및 셸 스크립트 실습
- IP 설정, DNS, DHCP, SSH 등 네트워크 서비스 구성
- 디스크 관리, RAID, LVM을 활용한 스토리지 구성 및 복구 실습
- 웹·DB·메일·파일 공유 서버 설치 및 운영
- 방화벽, 프록시 등 네트워크 보안 및 서비스 관리 실습
- 장애 상황 분석 및 복구 과정을 기록하여 서버 운영·관리 역량 향상

## 4. 가상머신 환경 구성
클라이언트 컴퓨터 1대와 서버 4대로 구성

## 5. 문제 상황
CentOS 7에서 IP 설정과 네트워크 연결 문제
yum 저장소와 RPM 패키지 의존성 문제
